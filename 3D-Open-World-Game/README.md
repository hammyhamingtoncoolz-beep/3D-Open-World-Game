# 3D Open World Game

A 3D open-world game project. This repo currently contains only a basic setup.

## Getting started

1. Clone the repo
2. Add your game code under `src/`
3. Put models, textures and audio under `assets/`

## Structure

```
src/      Game source code
assets/   Models, textures, audio
docs/     Design notes
```
